# Master of Programming 2023 - Honorable Mention

This repository contains my original algorithmic solutions from the national "Mistrz Programowania 2023" (Master of Programming) competition. I wrote the entire codebase independently, relying solely on my own skills (developed before the AI era).

## 🏆 Achievements & Certification
* **Honorable Mention:** Participation concluded with an official diploma of distinction.
* **Date:** March 10, 2023.
* **Results:** Ranked 185th, with visible scoring for individual tasks in the official ranking on the Szkopuł platform.

## 💻 About the Code
The scripts in this repository represent a raw, algorithmic approach to competitive programming problems. They focus on optimizing time complexity, memory efficiency, and the proper use of data structures.
